--------------------------------------------------
4. INSTALLATION
--------------------------------------------------

Nexora is a static HTML template.

To use the template:

1. Extract the ZIP package.
2. Open the project folder.
3. Upload the files to your web hosting.
4. Make sure index.html is located in the website root.
5. Open your domain in a browser.

You can also preview the template locally by opening
index.html in a modern web browser.
